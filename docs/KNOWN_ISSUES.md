# Known issues and external blockers

| ID | Issue | Impact | Workaround / next step |
|-|-|-|-|
| K-01 | **Android SDK and Google Maven unavailable in the first build environment** (`dl.google.com` / `maven.google.com` refused by the egress proxy; no Android SDK installed). | The `:app` module (Compose UI, renderer Views, export, parent area) could not be compiled, so there is **no APK, no device screenshots and no device QA yet**. Android library versions in `libs.versions.toml` are unverified. | The project owner created the environment **“Colora World (Android build)”** (allows Google hosts) and made it the project default. Continue in a session on that environment: install SDK, verify versions, implement `:app`. See `docs/CHECKPOINT.md`. |
| K-02 | No KVM / emulator acceleration in cloud containers. | Instrumented tests and screenshots need either a software-rendered emulator (slow) or the owner's device. | Use Robolectric + Compose screenshot tests where possible; run `connected*` tests on a real device. |
| K-03 | **Voice-over EN/VI not produced.** No licensed voice talent or commercial TTS service is available, and bundling neural TTS voices with unclear licences would break spec §21. | Lines will be shown as text with icons; optional device TTS fallback only. | Owner supplies recordings (script = `story.*`, `prompt.*`, `milo.*` keys in `assets/content/locales`) or a licensed TTS; pipeline will add `audio/voice/<locale>/<key>.ogg` + mapping. |
| K-04 | Music loop seam: the global reverb is applied after the loop wrap, so a few milliseconds of reverb tail are not wrapped. | Inaudible in most cases; needs a listening check on device. | If audible, apply reverb before wrapping (tools/audio/synth.py `loop`). |
| K-05 | Store billing / Play release need the owner's Play Console account, product IDs, signing key and policy forms. | `store` flavor can only be wired to real Play Billing once products exist; no fake purchases will ship. | See `docs/RELEASE_CHECKLIST.md`. |
| K-06 | Sound design was verified numerically (duration, peak, RMS, no clipping), not by listening, in this session. | Possible taste issues (e.g. instrument timbre). | Listen on device; tweak `tools/audio/synth.py`. |
| K-07 | Template, prop and character art was reviewed via contact sheets at thumbnail size only. | Small artefacts may show at full canvas size. | Review at full size in the studio; adjust sources in `tools/art`. |
